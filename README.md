# SpaceGameWeb 
Есть несколько основных сущностей: `юзеры`, `миры`, `планеты`, `майнеры`, `транзакции`. Юзеры могут взаимодействовать между собой посредством уничтожения миров друг-друга или же переводя ресурсы. На планеты можно навешивать щиты для защиты от атак.
Щиты тратят ресурсы, ресурсы можно добывать из планет с помощью майнеров.

## Usage

После

```bash
docker compose up
```

просто перейдите на `localhost:8004/` или `127.0.0.1:8004/`


## Кратко про архитектуру
В самом начале для раздачи статики используется `nginx`.
Под капотом логика на `fastapi` + `sqlalchemy`. При попытке пользователя загрузить конкретный мир, этот мир загружается из основной бд `postgres` и сохраняется в кэш - `redis`. Все действия которые должны быть обработаны с минимальной задержкой происхожят прямо в кэше. С некоторым интервалом фоновые таски в `celery` синхронизируют состояние основной бд с кэшем. Реализован механизм сессий, айдишник сессии хранится в cookies. При попытке взаимодействия с ручками апишки читается айди сессии и дальше идет какая-то логика.
